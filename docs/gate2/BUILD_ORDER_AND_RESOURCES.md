## F. First 7 days (Revision 1 — low-cost learning)

**Day 1** — *You:* freeze HPS v0 (sign off the literal questionnaire); select flagship Forum vantage; define the visual control condition (placard baseline text); lock Wave-1 experiment protocols (X-VPG, A1). *AI agents:* draft X-D0 200-question eval set; template the Track F cost ledger. *Produced:* frozen instrument, vantage, control condition, protocols. *Unlocked:* every Wave-1 test is now runnable the moment prototypes exist.
**Day 2** — *You:* build/verify the claim ledger for that vantage (founder-judgment work); write the ART-0 brief. *AI:* draft ledger entries with citations; start the cheap visual blockout (depth-layer composites from AI reconstruction drafts); finish D0 eval cases. *Produced:* ledger v1, ART-0 v0, D0 dataset. *Cash so far:* ~$0.
**Day 3** — *You:* run the D0 benchmark; grade unsupported claims (spot-check AI grader). *AI:* build the B1 interaction shell (web player) receiving ART-0. *Produced:* D0 results (possible first kill/pass, E0), B1 shell alpha. **No expensive art exists or is commissioned.**
**Day 4** — *You:* QA ART-0 for historical plausibility against the ledger. *AI:* build Lantern mode on the same shell/assets; start A1 audio scene independently (script draft + AI VO takes). *Produced:* Lantern v0, A1 draft audio. *Unlocked:* both visual interaction concepts testable on identical content.
**Day 5** — *You:* internal founder QA of B1 + Lantern; dictate interaction fixes (beam latency, transition feel); recruit 6–10 external testers (screener + incentives). *AI:* fix interaction problems; assemble session kit (randomization sheets, HPS forms). *Produced:* test-ready prototypes, booked participants.
**Day 6** — *You:* run **X-VPG** — first exploratory test: baseline vs B1 vs Lantern (Latin square, n≥6); collect HPS + IB/AC/TR/NV diagnostics; run A1 cells with the same cohort where session time allows. *AI:* live data entry/scoring. *Produced:* first user evidence, classified **E1/E2**. *Unlocked:* the ART-1 spend decision.
**Day 7** — *You:* run **X-B3-PREP** local instrumentation rehearsal (operational checklist ONLY — explicitly not VPS validation; no feasibility claims logged); analyze Week-1 results; fill the Decision Board; make first GO/ITERATE/KILL calls. *AI:* fix logging gaps; compile the analysis. *Produced:* B3-PREP checklist status, completed Day-7 Decision Board.
