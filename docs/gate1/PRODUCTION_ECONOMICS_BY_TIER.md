# PRODUCTION_ECONOMICS_BY_TIER.md
ChronoWalk 2.0 — Gate 1 · Track F · August 2026

Operational burden of producing **one additional stop** per experience tier. Estimates are planning-grade (founder-hours or contractor-cost bands, 2026 rates); each Gate 2 experiment must replace estimates with actuals. **We are not optimizing only for cheapness** — a costly interaction can be strategically correct if it becomes ChronoWalk's defining moment.

## Cost dimensions per stop

research · source collection · modern reference capture · reconstruction design · 2D asset production · 3D asset production · spatial calibration · device testing · historical review · localization · maintenance.

## Per-tier estimates (one additional stop, first language)

### T-A: Narrated Presence (A1–A2 class: premium narration + cinematic sound)
| Dimension | Estimate |
|---|---|
| Research + sources + ledger | 20–40 h founder/historian |
| Script + narrative design | 10–20 h |
| Voice (directed AI or human session) | $150–800 |
| Cinematic sound design | 15–30 h contractor ($750–2,500) |
| Reference capture | none required |
| Calibration | trigger zones only, 1–2 h |
| Historical review | 4–8 h |
| Localization (per added language) | ~20–30% of script+voice+QA cost |
| Maintenance | near-zero |
| **Total order of magnitude** | **~$2–6k equivalent per stop** |
**Suitability: every stop.** This is the floor tier and scales linearly with catalog.

### T-A+: + head-tracked spatial mix (A3) / Walking Score (A4)
Adds 8–20 h spatial mixing + on-site tuning walk. **Suitability: every stop** where content warrants; marginal cost modest once tooling exists.

### T-B1: Cinematic Then/Now vantage
Adds: matched reference photography (on-site, seasonal light) 4–8 h; reconstruction artwork (ledger-reviewed, confidence-styled) — **the dominant cost: $2–8k per vantage** commissioned, less if style system amortizes; depth-layer decomposition 4–8 h; review 4–8 h. Maintenance: low (site appearance drift over years).
**Suitability: selected premium stops** (1 vantage each), 2–5 per city.

### T-B2/B5: Camera-assisted 2.5D vantage (incl. Lantern)
T-B1 costs **plus**: reference capture set for feature-lock (2–4 h on site, multiple conditions); per-vantage calibration + device testing (est. 8–24 h in prototype era — the number X-B2 must pin down; must fall <4 h with tooling to scale); micro-story beats (B5) 5–10 h. Maintenance: **medium — recalibration risk** whenever the site changes (scaffolding is the enemy).
**Suitability: 1–3 flagship stops per city.**

### T-B3: True anchored AR moment
T-B2 costs **plus**: 3D asset (massing→dressed: $5–25k per scene depending on fidelity); VPS site scanning/validation field days; multi-device/multi-condition test matrix (largest hidden cost); provider fees (Niantic/Google usage). Maintenance: **high** — provider dependency + site changes + OS churn.
**Suitability: 1–3 flagship stops per city — possibly flagship cities only** until tooling matures.

### T-B4: Photoreal reconstruction scene
Authored photoreal 3D scene: **$15–60k+ per scene** (the art, not the tech, dominates); splat pipeline processing + device benchmarks; review of every visible element. Maintenance: medium (renderer churn).
**Suitability: flagship cities only, 1 scene — or experimental only** until X-B4 proves a presence premium over pre-rendered video.

### T-C: each additional authored era at an existing vantage
~60–80% of a T-B1 artwork cost per era (research overlaps, art doesn't).
**Suitability: selected premium stops**, only if X-C1 proves comprehension lift.

## Strategic reading

1. **The catalog runs on T-A/T-A+.** Unit economics of 100+ cities close only if the universal tier is audio-class cost.
2. **Art, not engineering, is the recurring cost driver** for every visual tier — a reconstruction-art *style system* (consistent visual language, reusable kit of Roman-architecture elements, confidence styling) is the highest-leverage cost investment, ahead of any rendering tech.
3. **Calibration hours are the scaling poison** for T-B2/B3. X-B2/X-B3 must measure them; Foundry tooling exists to crush them.
4. **A defining moment justifies flagship cost:** one T-B3/B4 showcase per flagship city can be the marketing engine for the whole catalog (the App Store screenshot argument) — evaluated as marketing + product spend, not per-stop content spend.
5. Localization multiplies **narration-layer** costs only; visual assets are language-free — visual tiers amortize *better* across languages.
