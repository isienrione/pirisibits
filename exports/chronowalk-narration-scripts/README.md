# ChronoWalk — Audio Narration Scripts / Transcripts

All stop and transit narration scripts used by the ChronoWalk Rome walk.

## Contents

### English (`en/`)
- `stops/` — waypoint chapter transcripts (from `src/content/rome/manifest.json`, plus master script for `enc_circus`)
- `transits/` — between-stop narration (manifest + master for `t02`, `t18`, `t19`)
- `other/` — system lines, inserts, path outros, resume greetings

### Spanish (`es/`)
- `stops/` & `transits/` — from `src/i18n/content/es/*.json` (canonical in-app spoken text)
- `other/system/` — resume greetings, no-ticket alternatives
- `production-scripts/` — full production markdown from `docs/spanish-audio/scripts/`
