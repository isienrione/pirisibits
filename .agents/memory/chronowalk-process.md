**Rule:** ChronoWalk 2.0 follows a strict founder-gated process (Gates 0–9 per the Master Pack in attached_assets). Do not build, scaffold, pick a stack, or generate content beyond the currently approved gate. Stop at gate boundaries and wait for explicit founder approval.

**Why:** The founder explicitly instructed a deep-understanding-before-building process; premature building violates the engagement and wastes work. Gate 0 (analysis, 11 docs in docs/gate0/) completed August 2026.

**How to apply:** Before any implementation request, check which gate is approved. Source-of-truth hierarchy: Playbook (Spanish PDF) > Master Pack > founder chat decisions > legacy artifacts > agent preference. Surface conflicts rather than silently choosing. Label tech capabilities honestly (established / needs prototyping / expensive / device-dependent / speculative / not recommended).
