# System UI cues

Shipped with the Vite app under `/rome/audio/system/`.

| File | Role |
|------|------|
| `ui_arrival_chime.mp3` | Notification chime on waypoint arrival |
| `ui_waypoint_unlocked.mp3` | Spoken “Waypoint unlocked!” after the chime |

Arrival sequence (every visit stop): chime → unlocked VO, plus haptic pulse/unlock.
