# Living Postcard — reusable production pipeline

Extracted from w01 reference pre-production (Day 3D).  
Reuse for Pantheon, Titus, Circus, and worthwhile reveals.

## Pipeline steps

1. **Lock Now** — choose shipping modern frame; portrait mobile; empty enough plate  
2. **Identify anchors** — pier/cornice/silhouette hinges; document in `01_CAMERA_LOCK`  
3. **Historical specification** — certain / probable / conjectural; honesty caption  
4. **Reconstruction base** — image-to-image to the Now camera (never reverse)  
5. **Add restrained life** — function/presence; reject Hollywood  
6. **Registration QA** — hold/release on phone; anchors must not swim  
7. **Still optimization** — ≤400KB; identical canvas to Now  
8. **Optional motion** — same camera; on-demand; ≤2.5–3MB; no cuts  
9. **Runtime integration** — manifest `now`/`then`/`loop`; collectors pick up paths  
10. **Real-phone QA** — outdoor brightness, immersive cover crop  
11. **Historical QA** — founder/scholar gates  
12. **Award `revealTier`** — only after scorecard PASS  

## Reuse map

| Step | Pantheon `w17` | Titus `w03` | Circus `enc_circus` | Worthwhile set |
|------|----------------|-------------|---------------------|----------------|
| Camera lock | Rotonda portico Now | Arch + Via Sacra axis | **Must rematch traveler view** | Same method |
| Historical matrix | Template | Template | Template | Template |
| Generation brief pattern | I2I, no generic T2I | Fresh city concept | Scale in-valley | Often still-only |
| Motion policy | OD after still | OD after still | OD after still | Usually still-only |
| Scorecard | Clone + place gates | Clone + city gates | Clone + scale gates | Shorter worthwhile gates |
| Hotspots | Only if exterior-visible | Optional | Optional | Rarely |

## Anti-patterns (all reveals)

- Beautiful recon from wrong camera  
- Wiring legacy `ancient-reconstruction.jpg` without registration  
- Awarding `revealTier` before QA  
- Mass-hydrating MP4s offline  
- Pseudo-Latin / AI text
