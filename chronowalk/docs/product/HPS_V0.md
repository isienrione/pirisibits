# HPS v0 — Frozen Instrument (Revision 1 — literal questionnaire)

Status: READY TO FREEZE. This is the complete, administrable instrument. Once the founder signs off, no wording changes until after Rome Trip 1.

## Administration
- 7-point scale for every item. Anchors printed at both ends of every row: **1 = "Not at all true for me" · 7 = "Completely true for me."**
- Delivered on paper or a separate device, immediately after each experience cell, before any conversation. Item order randomized within blocks. Facilitator script fixed; participants told "some versions are deliberately unfinished."
- ® = reverse-scored: score used = 8 − response.

## Scoring formulas
- **Subscales:** SP = (SP1+SP2)/2 · TP = (TP1+TP2)/2 · HL = (HL1+HL2)/2 · EW = (EW1+EW2)/2
- **CORE HPS = (SP + TP + HL + EW) / 4** (range 1–7)
- **IB diagnostic = ((8−IB1)+(8−IB2))/2** → reported on the *burden* direction as **IB-raw = (IB1+IB2)/2** (higher = worse; thresholds in the matrix use IB-raw, e.g. "IB ≤ 3.5")
- **AC diagnostic = AC-raw = (AC1+AC2)/2** (higher = worse; desk sessions AC-raw = AC1)
- **TRUST diagnostic = (TR1+TR2)/2**
- **NOVELTY diagnostic = NV1** (never enters any score; reported alongside)
- **ΔHPS** = core HPS(test cell) − core HPS(comparator cell), within-subject.

## Attention-conflict VETO (explicit)
An experience **cannot be declared a pass, whatever its HPS**, if at a real site:
- mean AC-raw > 4.5, **or**
- AC-raw rises ≥ +1.5 versus its control cell.
Rationale: ChronoWalk must not succeed by making the phone more impressive than Rome. If HPS rises *and* AC rises past the veto line, the verdict is **ITERATE (attention design)**, never PASS — the experience is redesigned to return eyes to the site (audio-forward, glanceable visuals, lantern-style brief looks) and re-tested. The AC veto outranks every success threshold in the matrix.

## Anti-wow controls
- NV1-vs-HPS divergence reported per cell: high NV1 + low core HPS = spectacle, flagged explicitly.
- **Second-exposure rule:** a passing cell must retain ≥ 85% of its core-HPS delta on second exposure (same/next day) before graduating to further investment.
- EW items reference the place/moment, never the technology.

## Triangulation block (unchanged)
- Forced choice after paired cells ("keep only one on your trip?") + one-line reason.
- +24h unprompted-narrative probe, blind-scored place-vs-app.
- Behavioral logs: dwell time, gaze-up where observable, voluntary replays.

## Evidence levels
Every reported result carries an evidence class per the matrix R1.1: E0 founder/technical · E1 usability signal · E2 directional user evidence · E3 decision-grade prototype evidence · E4 field-confirmed. This instrument at min-N produces E1–E2; at preferred-N with counterbalancing, E2–E3; Rome cells E3–E4.
