## Preserved on purpose

- **Pricing intro** — single shared statement that every package includes GPS narration, offline download, Pantheon preview.
- **Tier bullets** — only differentiating coverage (stops, Threshold availability, park-ticket note, reorder).
- **Pricing footnote** — ticketed-entry restriction.
- **FAQ** — full purchasing, offline, GPS accuracy, subscription, group-tour, Threshold, and narration answers.
- **Threshold section** — interactive reconstruction (not a repeated bullet list).
- **Real-moment “Pause when Rome distracts you”** — scenario voice, not a feature grid.
