# ChronoWalk Design Directive

Binding philosophy for all UI work. Complements [DESIGN_LAW.md](../../DESIGN_LAW.md) (palette, tokens, banned patterns).

ChronoWalk is a **premium historical storytelling product**, not a tourism app.

## Never

- Redesign
- Introduce trendy UI
- Chase Dribbble aesthetics
- Add decoration for its own sake
- Increase complexity

## Always

Refine in place. Preserve the existing visual language while making it:

- Calmer
- More immersive
- More premium
- More emotionally resonant

## Philosophy

- Apple Human Interface Guidelines
- Editorial print design
- Museum exhibition design
- Luxury publishing
- Slow interfaces
- Cinematic storytelling
- Quiet confidence

## Gate (ask before every UI change)

1. Does this **reduce cognitive load**?
2. Does this **increase immersion**?
3. Does this **improve consistency**?
4. Does this **preserve the ChronoWalk identity**?
5. Would Jony Ive **remove rather than add**?

If any answer is **no**, do not implement the change.

## Prefer

**Subtraction over addition.**

Every commit should make the product feel more **timeless**, not more fashionable.
