==================================================
THRESHOLD / HISTORICAL RECONSTRUCTION
==================================================

The existing Then/Now slider is a powerful concept but NOT a permanent implementation requirement.

One example of a more ambitious direction is:

User raises the camera
→ app helps align the physical monument
→ interface says:

"Hold to restore Rome."

→ user holds
→ the missing historical architecture appears over the live contemporary scene
→ releasing or moving allows comparison between past and present.

IMPORTANT:

It does NOT necessarily have to be geometrically perfect, persistent world-scale AR to feel magical.

A premium camera-assisted reveal using:
- guided viewpoint
- visual alignment
- perspective-matched reconstruction
- feature matching
- segmentation
- depth-aware compositing
- subtle parallax
- lightweight 3D

may produce most of the emotional impact at dramatically lower production cost.

However, this is NOT an instruction to avoid true AR.

If true AR materially improves the experience and is practical for a flagship stop, investigate it seriously.

"Hold to restore Rome" is also an EXAMPLE, not sacred copy.

If you invent something materially better, propose it.

Preserve the revelation, not the mechanism.

At least one interaction in the first production-quality ChronoWalk experience should aspire to create this reaction:

"I have never experienced a city like this before."
